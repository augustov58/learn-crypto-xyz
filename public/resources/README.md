# Resources Folder

This folder contains downloadable resources (PDFs, documents, etc.) for the Learn Crypto platform.

## How to Add Resources

1. **Upload your file** to this folder (`public/resources/`)
2. **The file will be accessible** at `/resources/your-filename.pdf`
3. **Tell Claude** the filename and details so it can add it to the topics

## Example

If you upload `quilibrium-report.pdf` to this folder:
- It will be accessible at: `/resources/quilibrium-report.pdf`
- The full URL on production: `https://your-domain.com/resources/quilibrium-report.pdf`

## Supported File Types

- PDFs (`.pdf`)
- Documents (`.doc`, `.docx`)
- Images (`.png`, `.jpg`, `.svg`)
- Any other file type you want to share
